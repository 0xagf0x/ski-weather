
# Ski Map

A web application that displays ski resorts on a **Mapbox** interactive map, plus current and weekly weather forecasts from **WeatherAPI**. You can also mark favorite resorts and quickly view their conditions.

## Features
- **Interactive Resort Map** powered by [Mapbox](https://docs.mapbox.com/).
- **Current Weather** data from [WeatherAPI](https://www.weatherapi.com/).
- **Weekly Forecast** with highs, lows, and weather icons.
- **Favorites** functionality for quick resort access.

---

## Prerequisites
- **Node.js** (v14+ recommended)
- A **Mapbox** access token (if you use Mapbox publicly, you’ll include it in your code/config).
- A **WeatherAPI** key (free sign-up at [weatherapi.com](https://www.weatherapi.com/)).

---

# How to Start the Ski Map App

1. **Install Dependencies**  
   ```bash
   npm i

2. **Start the Development Server**  
   ```bash
   npm run start

3. **This launches the app on http://localhost:3000 (by default) in your browser.**
